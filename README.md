## Estructura del proyecto

```
retiro-elsantuario/
├── index.html   # Landing page (archivo único, todo incluido)
└── README.md
```

La página es un **único archivo HTML** con CSS y JS embebidos. Sin dependencias locales ni frameworks. Las únicas peticiones externas son las fuentes de Google Fonts.

---

## Tecnologías

- HTML5 / CSS3 / JavaScript vanilla
- Fuentes: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond), [Dancing Script](https://fonts.google.com/specimen/Dancing+Script), [Montserrat](https://fonts.google.com/specimen/Montserrat)

## Cómo usar

No requiere instalación ni build. Abre directamente en el navegador:

```bash
open index.html
```

Para publicar, sube `index.html` a cualquier hosting estático (Netlify, Vercel, GitHub Pages, etc.).
